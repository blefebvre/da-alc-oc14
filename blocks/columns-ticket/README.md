# columns-ticket

Custom **columns** block. Purpose: lottery-ticket-details.

## Authoring (Document Authoring)

Model: `standalone`

Block table, one row, two cells. Cell 1: a "Game #n" paragraph (shown as a vertical label) and the ticket image. Cell 2: one paragraph per info line with the label in bold (Top prize, Prizes Available, Overall chance of winning a prize), then an optional "SEE ALL TOP PRIZES REMAINING" link paragraph.
