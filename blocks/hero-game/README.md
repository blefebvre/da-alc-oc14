# hero-game

Custom **hero** block. Purpose: game-detail-banner.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell of content.

## Supported variations

No variations.

## Universal Editor fields

N/A (Document Authoring project)

## Content structure

Row 1: banner image (alt empty or game name). Row 2: CTA paragraph(s): a bold link '**[Play now](...)**' as the primary pill button and a plain link '[TRY DEMO](...)' as a secondary chevron text link. Live-casino pages use a single bold '**[Browse Games](...)**' link. Breadcrumbs are not authored; scripts.js overlays them when page metadata 'Breadcrumbs: true'.
