# tabs-boxed

Custom **tabs** block. Purpose: game-instructions-and-odds.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell of content.

## Supported variations

No variations.

## Universal Editor fields

N/A (Document Authoring project)

## Content structure

One row per tab: cell 1 = tab label ('How to Play', 'Prizes & Odds'); cell 2 = panel content (paragraphs, PDF download links, lists). Keep every tab and its label even when a panel is empty or only says 'SEE IN GAME FOR PRIZE STRUCTURE'. Drop empty paragraph/line-break fillers.
