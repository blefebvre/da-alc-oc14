# carousel-thumbnails

Custom **carousel** block. Purpose: game-screenshot-gallery.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell of content.

## Supported variations

No variations.

## Universal Editor fields

N/A (Document Authoring project)

## Content structure

One row per screenshot, a single cell with the image (with its alt text). No text cell. The block builds the thumbnail strip from the same images; do not author thumbnails separately.
